SIGNAL

The dot that tells you if you're on track.

A ring at 60% means nothing on its own. Is that good or bad? It depends where you are in the window.

The pace dot shows where your fill would sit if you'd used the quota evenly since the window opened. If your ring is ahead of the dot, you'll run out of tokens. If it's behind, you have room.

That's the difference between data and signal. Tokenomics shows you both.

Understanding this signal helps you learn how prompts and models use tokens differently, so you can tune your session to fit your budget.

BREADTH

Every tool you run, in one place.

Most of us don't use just one AI tool. Tokenomics detects which ones you have installed and shows them all — usage rings in the menu bar, full detail in the popover, a dashboard on your desktop.

Drag to reorder. Hide the ones you're not using today. The menu bar shows the one you're closest to hitting.

Zero-friction authentication

No token pasting. No cookie hunting.

Coding tools already keep your sign-in on your Mac. Tokenomics reads each one where it lives: macOS Keychain for Claude, the gh CLI for Copilot, local configuration files for Cursor, Codex CLI and Gemini CLI.

Web tools like ChatGPT and Midjourney don't leave anything on your Mac, so the browser extension reads them from the sites you're already signed in to. Stability AI and Runway take an API key you paste once. That's the most friction you'll hit.

Claude Code's sign-in lives in your Mac's Keychain, so macOS asks once before Tokenomics can read it. Choose Always Allow and you won't be asked again. When Claude Code refreshes its sign-in, Tokenomics picks up the new one on its own.

FAQ

Common questions.

Is it free?

Yes. The Mac app and the browser extension are both free to download and use. There's no subscription, no paid tier, and no feature gating.

How does signing in work? Do I need to paste any tokens?

Not for most tools. The Mac app reads the sign-in your coding tools already keep on your Mac: macOS Keychain for Claude, the gh CLI for GitHub Copilot, and local configuration files for Cursor, Codex CLI and Gemini CLI. The browser extension uses the sites you're already signed in to. Only Stability AI and Runway need an API key, pasted once and kept in the macOS Keychain.

Does it send my API keys or credentials anywhere?

No. Tokenomics uses your sign-ins only to ask each AI service for your own usage, and keeps the numbers on your device. Nothing goes to any server the author controls: no analytics, no telemetry, no tracking code in the app or the extension. The full breakdown is on the Privacy page.

Is it open source?

You can read every line on GitHub. The license is source-available rather than MIT — it keeps commercial rights reserved so I have room to build paid capabilities later (a team or enterprise version is one possibility). The current app is free forever for anyone who installs it. This isn't a SaaS in disguise.

macOS only? What about Windows and Linux?

macOS only for now (14 Sonoma or later). The menu bar is a macOS-native concept and the auth paths (Keychain, gh CLI, local config files) are Mac-specific. A Windows/Linux version of the app is on the roadmap. In the meantime, the browser extension works in Chrome on Windows and Linux today.

Which AI tools does it work with?

Coding tools: Claude Code, Codex CLI, Gemini CLI, GitHub Copilot and Cursor. Chat: Claude, ChatGPT, Gemini, Grok and Perplexity. Creative: Midjourney, Leonardo, Stability AI, Runway, ElevenLabs, Suno and Udio. The web tools connect through the browser extension. The full list says how each one connects.

Why not just open a browser tab and check the dashboard?

You could. The problem is that you don't know you need to check until you're mid-task and something breaks. The pace dot is specifically useful here: it shows whether you're on track to hit a limit before you actually do, so you can make a call about whether to start a long agentic run.

A dashboard answers "how much have I used?" — Tokenomics answers "am I about to run out?"

How is it different from other Claude/AI usage trackers?

Two things: breadth and signal quality. Breadth: your coding tools, chat apps and creative tools in one place, not just Claude. Signal quality: the pace dot. Most usage meters show a percentage. Tokenomics shows whether that percentage is ahead of or behind where you'd expect given how much of the window has elapsed. That turns a number into an answer.
