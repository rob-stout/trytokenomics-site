Setup guide

Connect your tools.

The Mac app connects to your coding tools, plus Stability AI and Runway. Web tools like ChatGPT and Midjourney connect through the browser extension. Pick a tool below for the exact steps the app walks you through.

Claude Through Claude Code GitHub Copilot Through the GitHub CLI Cursor The Cursor app Codex CLI OpenAI's coding agent Gemini CLI Google's coding agent API keys Stability AI · Runway Browser extension ChatGPT, Gemini app and more

Before you start

Where setup starts

Every tool connects through the same guided setup window. There are two ways to open it.

  1. From a tool's row in AI Connections

    Click Tokenomics in your menu bar, then the gear icon at the bottom of the popover. In Settings, click AI Connections. The screen that opens is titled "Providers" and lists every tool.

    Each tool that isn't connected has a button on its row:

    • Connect when it isn't set up yet.
    • Sign In when the tool is installed but signed out.
    • Reconnect when its sign-in has expired.
    • Allow Access when macOS needs to let Tokenomics read Claude Code's sign-in (see Claude).

    Connect, Sign In and Reconnect open the guided setup window for that tool, titled "Connect" plus the tool's name, for example "Connect Anthropic".

  2. From Setup providers…

    In Settings, click Setup providers…. If nothing is connected yet, it starts the full walkthrough: you check off the tools you use, then follow "Your shortest path" with Start setup. If you've been through setup before and have tools connected, it opens "Add a provider", a list you pick from.

Already installed and signed in? Tokenomics checks your Mac first. If a tool is already set up, it connects without the install steps. On install screens, a link like Already have Homebrew? Skip this step lets you skip anything you already have.
When it's done, the window says the tool "is connected" and offers I'm all set to finish. If a tab in the popover says the tool "isn't set up yet", its Set Up button opens the same window.

No surprises

What setup may install on your Mac

Tokenomics only installs what a tool needs, and only after you click the install button. Each install screen shows the exact command first.

  • Claude Code (for Claude). Anthropic's own installer, curl -fsSL https://claude.ai/install.sh | bash. It installs into your home folder and puts claude in ~/.local/bin. No password needed. Tokenomics then adds one line to ~/.zprofile (or ~/.bash_profile if your shell is bash) so claude works in Terminal: export PATH="$HOME/.local/bin:$PATH". It skips this if the file already mentions .local/bin.
  • Homebrew (for GitHub Copilot, Codex CLI and Gemini CLI, only if you don't have it). Homebrew's official installer, from brew.sh.
  • GitHub CLI (for Copilot). Installed with brew install gh.
  • Node.js (for Codex CLI and Gemini CLI, only if you don't have it). Installed with brew install node.
  • Codex CLI and Gemini CLI. Installed with npm into ~/.tokenomics-cli, a folder of their own, so they stay out of your global npm. Tokenomics doesn't add this folder to your Terminal's PATH.
  • Gemini CLI settings. If ~/.gemini/settings.json doesn't say how to sign in yet, Tokenomics sets it to sign in with Google. Other settings in the file are left alone.
  • Cursor and the browser extension aren't installed by Tokenomics. It opens their download pages for you.

When Terminal opens

  • To install Homebrew. Its installer needs a real Terminal window.
  • To sign in to Claude Code, which runs Anthropic's own sign-in in Terminal.
  • The first time, macOS asks whether Tokenomics may control Terminal. Allow it. If you said no, see If something goes wrong.

Everything else (the GitHub CLI, Node.js, Codex CLI, Gemini CLI, and their sign-ins) runs in the background while the setup window shows progress.

When you're asked for your Mac password

  • In Terminal, while Homebrew installs. You're asked once. Nothing shows as you type, which is normal.
  • In a macOS Keychain prompt, so Tokenomics can read Claude Code's sign-in. It may ask twice. Choose Always Allow each time.

Claude

Tokenomics shows Claude's 5-Hour Window and 7-Day Window. Chats on claude.ai and Claude Code share these limits. The Mac app reads them through Claude Code's sign-in, so setup installs Claude Code and walks you through signing in. In AI Connections, Claude is the Anthropic row.

Only use claude.ai?

The browser extension reads Claude from claude.ai, so you'll see your limits in the extension without Claude Code. The Mac app is different: it only shows Claude through Claude Code's sign-in. Without Claude Code, Claude won't appear in the menu bar or widgets. To get it there, follow the steps below.

  1. Open setup

    In Settings → AI Connections, click Connect on the Anthropic row. The "Connect Anthropic" window opens and checks your Mac.

  2. Install Claude Code

    The "Install Claude Code" screen shows the command Tokenomics will run. Click Install Claude Code. It takes about a minute and needs no password.

    $ curl -fsSL https://claude.ai/install.sh | bash
    Already have Claude Code? Click Skip this step to go straight to sign-in. If it's installed and signed in, Tokenomics skips all of this.

  3. Preview the sign-in, then open Terminal

    "Sign in to Claude Code" lists what Claude Code will ask. Click Continue. "After you sign in" covers the last two steps. Click Open Terminal. Terminal opens and starts Claude Code.

  4. Sign in, in Terminal

    Claude Code walks you through it:

    • Pick a login method. On Pro or Max, choose Claude account with subscription.
    • Sign in in your browser and paste the email code Anthropic sends.
    • Authorize Claude Code to connect to your account.
    • Accept Anthropic's security notes.
    • Pick a folder Claude can access. If you don't have one, create a Projects folder in your home folder.
    • Grant macOS permissions as Claude Code asks for them.
    Folder prompts: Claude Code may ask macOS for access to folders like Music, Photos, Downloads and Documents. It's safe to decline anything outside your Projects folder. Claude works fine without them.

  5. Come back to Tokenomics

    The window shows "Confirm login" and waits. You're done when Terminal shows Claude's chat prompt. Close Terminal and return to the window. If it hasn't moved on, click I'm signed in — check now.

  6. Allow Keychain access, if asked

    If you see "Allow keychain access", click Allow Access. macOS may ask twice. Enter your Mac password and choose Always Allow each time.

    What you'll see: "Anthropic is connected."

How you'll know it worked

The Claude tab shows two bars, 5-Hour Window and 7-Day Window. Until you start a 5-hour session, that bar says "No active session". For more on these limits, see how Claude's limits work.

Claude: common issues

"Tokenomics needs permission to read your Claude Code sign-in"

Claude Code is signed in, but macOS hasn't let Tokenomics read its sign-in yet. Click Allow Access in the popover or on the Anthropic row in AI Connections. Enter your Mac password and choose Always Allow, twice if macOS asks twice.

"macOS didn't allow access. Try again."

The Keychain prompt was closed or denied. Click Allow Access again and choose Always Allow, not Deny. If Claude Code is actually signed out, use Signed out of Claude Code? Sign in again in the setup window instead.

"Anthropic authentication expired"

Claude Code's sign-in has run out. Click Reconnect. The window shows "Sign in to Claude Code again". Click Open Terminal and sign in. Folder and permission steps are skipped this time.

Terminal says "command not found: claude"

The setup window opens Claude Code by its full path, so this only matters when you type claude yourself. Open a new Terminal window so it reads the PATH line setup added. If your shell isn't zsh or bash, Tokenomics leaves your shell files alone; add ~/.local/bin to your PATH yourself.

GitHub Copilot

Tokenomics shows your Copilot usage and limits, as GitHub reports them for your plan. It reads them through the GitHub CLI (gh), so setup installs gh and signs you in with it. There's no token to paste.

  1. Open setup

    In Settings → AI Connections, click Connect on the GitHub Copilot row. In the "Connect GitHub Copilot" window, click Sign in with GitHub.

  2. Install Homebrew, if you don't have it

    Click Install Homebrew. Terminal opens and runs Homebrew's installer. Press Return and enter your Mac password when asked. The setup window says "Waiting for Terminal…" and carries on by itself once Homebrew is ready. It takes about 2 minutes.

  3. Install the GitHub CLI

    Click Install GitHub CLI. This runs in the background.

    $ brew install gh
    Already have gh? Click Skip this step. If you've already signed in with gh auth login, Tokenomics connects right away.

  4. Approve in your browser

    Tokenomics runs gh auth login for you and opens GitHub in your browser. The window says "Waiting for you to approve in your browser…". GitHub asks for a one-time code: Tokenomics shows it under "If asked for a code", with a copy button. Enter it on github.com/login/device and approve. If the page didn't open, click Reopen browser.

    What you'll see: "GitHub Copilot is connected."

How you'll know it worked

On a paid plan (Pro, Pro+, Business, Enterprise) the Copilot tab shows one bar, Premium Requests, with how many you've used this month and when they reset. On the free plan it shows Chat and Completions. More in what the Copilot meters show.

Cursor

Cursor is a separate Mac app. Once it's installed and you've signed in to it once, Tokenomics reads your usage from Cursor's own settings on your Mac. Nothing extra is installed.

  1. Open setup

    In Settings → AI Connections, click Connect on the Cursor row. In the "Connect Cursor" window, click Connect Cursor.

  2. Install Cursor

    On "Install Cursor", click Install Cursor. Tokenomics opens cursor.com/downloads, Cursor's official download page. Download it and move it to your Applications folder. The window waits and notices when Cursor appears.

    Already installed? Click Already installed Cursor? Check now. If Cursor is installed but you're signed out, the window shows "Sign in to Cursor" instead. Click Open Cursor.

  3. Sign in inside Cursor

    Sign in in the Cursor app. The window says "Waiting for you to sign in to Cursor" and picks it up automatically. If it doesn't, click I'm signed in — check now.

    What you'll see: "Cursor is connected."

How you'll know it worked

The Cursor tab shows one bar, Premium Requests, for your current billing cycle, with "used / limit" under it. If your plan has no request limit (for example, Cursor's free plan), the bar shows Cursor's own usage message or a count of requests used instead.

Codex CLI

Codex CLI is OpenAI's coding agent, in Terminal. Tokenomics shows its 5-Hour Window and Weekly limits, read from the session files Codex keeps on your Mac. In AI Connections it's the Codex CLI row under OpenAI.

ChatGPT is separate

ChatGPT and Codex CLI share an OpenAI login but have separate limits. Chats on chatgpt.com connect through the browser extension, not this setup. See why ChatGPT and Gemini show two meters.

  1. Open setup

    In Settings → AI Connections, click Connect on the Codex CLI row. The "Connect OpenAI" window opens and checks your Mac for Homebrew, Node.js and Codex.

  2. Install Homebrew, if you don't have it

    Click Install Homebrew. Terminal opens and runs Homebrew's installer. Press Return and enter your Mac password when asked. The setup window carries on by itself once Homebrew is ready.

  3. Install Node.js, if you don't have it

    Click Install Node.js. About 30 seconds, in the background.

    $ brew install node

  4. Install Codex CLI

    Click Install Codex CLI. About 30 seconds. It goes into ~/.tokenomics-cli, not your global npm.

    $ npm install -g @openai/codex
    Already have Codex? Click Skip this step. If Codex is installed but signed out, the window shows Sign in with OpenAI instead.

  5. Sign in to OpenAI

    Tokenomics runs codex login for you and opens OpenAI's sign-in in your browser. Sign in with your OpenAI account. If the window shows a code under "If asked for a code", enter it when asked. If the page didn't open, click Reopen browser.

    What you'll see: "OpenAI is connected."

How you'll know it worked

The Codex CLI section shows a 5-Hour Window bar. The numbers come from Codex's own session files, so they only change after you use Codex. Until then the bar reads "No active session", and the Weekly bar appears once Codex has recorded a weekly limit.

Gemini CLI

Gemini CLI is Google's coding agent, in Terminal. Tokenomics counts your requests and tokens from the session files Gemini CLI keeps in ~/.gemini, and compares them with the daily limits of the plan you pick. In AI Connections it's the Gemini CLI row under Google.

The Gemini app is separate

The Gemini app at gemini.google.com and Gemini CLI share a Google account but track usage separately. The Gemini app connects through the browser extension.

  1. Open setup

    In Settings → AI Connections, click Connect on the Gemini CLI row. The "Connect Google AI" window opens and checks your Mac for Homebrew, Node.js and Gemini CLI.

  2. Install Homebrew and Node.js, if you don't have them

    Same as for Codex CLI: click Install Homebrew (Terminal opens and asks for your Mac password), then Install Node.js (brew install node, in the background). Use the Skip this step links for anything you already have.

  3. Install Gemini CLI

    Click Install Gemini CLI. About 30 seconds. It goes into ~/.tokenomics-cli, not your global npm.

    $ npm install -g @google/gemini-cli

  4. Sign in with Google

    Tokenomics starts Gemini CLI, which signs you in the first time it runs. The window asks: "Tokenomics will open Google's sign-in page in your browser to connect Gemini. Continue?" Click Open browser to sign in, then sign in with Google in your browser. If the page didn't open, click Reopen browser.

    Already signed in to Gemini CLI? If you've signed in by running gemini in Terminal before, Tokenomics connects without this step. If it's installed but signed out, the window shows Sign in with Google.

  5. Choose your Gemini plan

    Open the Tokenomics popover. The first time, the Gemini CLI section asks you to "Choose your Gemini plan". Pick Free, Standard or Enterprise and click Start Tracking. Tokenomics uses your plan to calculate daily limits:

    • Free: 1,000 requests a day, 60 a minute.
    • Standard: 1,500 requests a day, 120 a minute.
    • Enterprise: 2,000 requests a day, 120 a minute.

How you'll know it worked

The Gemini CLI section shows two bars, Tokens Today and Requests Today. Both reset at midnight Pacific time. Google doesn't report these numbers, so they're Tokenomics' own count from your Mac, measured against your plan's limits. Treat them as estimates. Use Gemini CLI on another computer and it won't be counted here.

Change your plan later: click the plan badge in the popover ("Change Gemini plan", then Update), or use the Free / Standard / Enterprise control on the Gemini CLI row in AI Connections.

API keys

Stability AI and Runway connect with an API key you paste once. Nothing is installed and no Terminal opens. Tokenomics keeps the key in your Mac's Keychain.

Looking for ElevenLabs? It now connects through the browser extension, not an API key in the Mac app. If you added an ElevenLabs key in an earlier version of the Mac app, it keeps using that key. See how to set up ElevenLabs.

  1. Open setup

    In Settings → AI Connections, click Connect on the Stability AI or Runway row. In the "Connect Stability AI" or "Connect Runway" window, click Enter API key.

  2. Get a key

    Click Open Stability AI or Open Runway. Tokenomics opens the provider's key page:

    • Stability AI: Account → API Keys. Making a new key lets you revoke it on its own later.
    • Runway: find or create your key under Account settings.

    Copy the key. Already have one? Click Skip to paste.

  3. Paste it

    On "Paste your API key", paste the key (or click Paste) and click Save & connect.

    What you'll see: "Stability AI is connected." or "Runway is connected."

How you'll know it worked

The tab shows a Credits bar. Stability AI shows credits remaining. Runway shows credits used out of your total.

API keys: common issues

“That key didn't work. Check it and try again.”

Tokenomics tries the key before saving it, and the provider turned it down. Check you copied the whole key, or make a new one, then paste it again and click Save & connect. Nothing was saved, so a key that already worked keeps working.

If it says “Couldn't reach Stability AI to check that key” (or Runway), the key may be fine; Tokenomics just couldn't get through. Check your internet connection and try again.

“API key no longer works”

A key that used to work was revoked or expired. Click Update key on that tab and paste a new one, or change it in Settings → AI Connections.

I want to use a different key

In AI Connections, switch the provider's toggle off. A Disconnect button appears. Click it to remove the saved key, then click Connect and paste the new one.

Browser extension

Web tools connect through the free browser extension: ChatGPT, the Gemini app, Midjourney, Leonardo, Grok, Perplexity, Suno and Udio, plus Claude and ElevenLabs from their websites. It reads the sites you're signed in to.

  1. Install the extension

    Get it from the Chrome Web Store. Versions for Microsoft Edge and Safari are on the way.

    From the Mac app: click Connect on a web tool's row in AI Connections (ChatGPT, for example). On "Install the browser extension", click Open Chrome Web Store. Not now? Click Skip for now.

  2. Open the Mac app once

    After installing the extension, open the Tokenomics Mac app at least once. That's when it links up with your browser. The setup window shows "Connecting the extension" and moves on by itself, usually within a few seconds.

    What you'll see: "The browser extension is connected."

Using it with the Mac app

Once linked, your web tools show in the menu bar, popover and widgets. Claude is the exception: the Mac app always reads Claude through Claude Code, so a claude.ai-only Claude shows in the extension but not the Mac app. If Safari is your default browser, the setup window says Safari support is on the way and suggests Chrome, Brave or Arc for now (more on that). Troubleshooting

If something goes wrong

The setup window shows what went wrong in red, with one button to fix it. Here's each message and what to do.

"Tokenomics needs permission to open Terminal. Go to System Settings → Privacy & Security → Automation and allow it."

macOS blocked Tokenomics from opening Terminal, which it needs for Homebrew and for Claude Code's sign-in. Click Open System Settings. Under Privacy & Security → Automation, find Tokenomics and switch on Terminal. Then come back and click Try again.

"Homebrew install was cancelled. You'll need to approve the admin prompt to continue."

Click Try install again. When Terminal asks, press Return and type your Mac password. Nothing shows as you type; press Return when you're done.

"Homebrew couldn't download. Check your internet connection and try again."

Homebrew, or something installed with it, couldn't reach the internet. Check your connection and click Retry.

"Setup couldn't finish." followed by a reason

An install stopped partway. The reason after it tells you which:

  • "Homebrew's installer stopped before finishing. Check the Terminal window for details, then try again." Read the last lines in Terminal, fix what it says, then click Try setup again.
  • "Homebrew didn't finish installing. If Terminal is still working, let it finish, then try again." Let Terminal finish, then click Try setup again.
  • "Claude Code couldn't download. Check your internet connection and try again." Check your connection, then click Try setup again.
  • "Please try again." or any other reason: click Try setup again. If it keeps happening, tell us what it said.
"We couldn't find … after installing it. Try re-running detection."

An install reported success, but the tool (Claude Code, Homebrew, Node.js or the GitHub CLI) wasn't where Tokenomics looks for it. Click Re-detect. If the same message comes back, cancel and start the setup again so the install runs again.

"Permission denied writing to …. Tokenomics will clear its install cache and try again."

Usually a leftover from an earlier failed install. Click Clear cache & retry.

"We didn't detect a sign-in. If you finished signing in, tap Check now."

The window waited a long time without seeing a sign-in. If you did sign in, click Check now. If you didn't, click Check now and finish signing in in your browser, Terminal or the Cursor app.

My browser didn't open to sign in

For GitHub Copilot, Codex CLI and Gemini CLI, click Reopen browser in the setup window.

A popover tab says it "isn't set up yet" or "isn't signed in"

Click the Set Up button on that tab (for example Set Up Claude). It opens the guided setup for that tool. A tab that says its "authentication expired" has a Reconnect button that does the same.
