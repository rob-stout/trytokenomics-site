Help / How AI limits work

How do Claude's usage limits work?

Claude has a 5-hour session limit and a weekly limit, shared across chats, Claude Code and the desktop app. Max and Ultra also have a separate weekly Fable limit.

The limits

  • 5-hour session. Starts with your first message and resets in full five hours later.
  • Weekly limit, all models. Resets at a fixed day and time assigned to your account. It doesn't depend on when you started chatting or when you subscribed.
  • Weekly Fable limit (Max and Ultra). Fable uses your limits faster than other models, and has its own weekly cap of up to half your weekly limit. On Pro, Fable runs on usage credits.

Anthropic doesn't publish message counts. How far a limit goes depends on the model, how long the conversation is, the features you use and the effort level.

By plan

  • Free: limited usage every 5 hours and every week. No Claude Code.
  • Pro ($20/month): more than Free. Includes Claude Code.
  • Max ($100/month): 5× Pro, every 5 hours and every week.
  • Ultra ($200/month): 10× Pro every week, and no 5-hour limit once your account is verified (it happens automatically). If Settings → Usage shows no “Current session” bar, you're verified.

Plan names changed in late 2026: the old Max 20x is now Ultra, and Max 5x is now just Max.

What shares a limit

Chats on claude.ai, the desktop app, Claude Code and Claude Code in your editor all draw from the same limits. A long coding session can leave less room for chat, and the other way round.

When you hit a limit

  • Wait for the reset, or upgrade (new limits apply right away).
  • Turn on usage credits (formerly “extra usage”) in Settings → Usage, and your work continues at API rates instead of stopping. You can set a monthly spending cap. More on usage credits.
  • Claude Code gets a small wrap-up allowance so it can finish what it's doing.

The monthly API credits included with Max and Ultra can't be used in the Claude apps or Claude Code.

Where to check

Settings → Usage on claude.ai, or /usage in Claude Code. How to check your Claude usage.

In Tokenomics

The 5-hour window is the inner ring and the weekly window the outer ring, each with a pace dot. On Ultra, you'll see only the weekly window, because there's no 5-hour limit to show.

Checked against each provider's own pages in November 2026. Providers change limits often, so their usage page is the final word.
