Help / Getting set up

How do the Mac app and the browser extension work together?

The Mac app reads your coding tools, the extension reads your web tools, and they share usage numbers on your computer so each shows the full picture.

Each one reads the tools it can reach. Then they share what they read, so both show the full picture.

Who reads what

Read byTools
Mac appClaude (through Claude Code's sign-in), Codex CLI, Gemini CLI, GitHub Copilot, Cursor, and Stability AI and Runway with an API key
Browser extensionChatGPT, Gemini, Midjourney, Leonardo, Grok, Perplexity, Suno and Udio, plus Claude and ElevenLabs from their websites

What the Mac app gets from the extension

Everything the extension reads from a web-only tool shows in your menu bar, popover, widgets and notifications, usually within a second or two of the extension reading it.

When your browser is closed, the Mac app keeps showing the last reading, marked “Last read 2h ago”, for up to two days or until that limit resets. Usage can't go down until a reset, so the last number is still a safe guide.

Two tools can come from either side, and the Mac app picks one:

  • Claude: the Mac app always uses Claude Code's sign-in. Chats and Claude Code share the same limits, so the website reading would show the same numbers. If you only use claude.ai and don't have Claude Code, Claude shows in the extension but not in the Mac app.
  • ElevenLabs: the Mac app uses the extension's reading. If you added an ElevenLabs API key in an earlier version of the Mac app, it keeps using that key instead.

What the extension gets from the Mac app

The extension's popup also shows Codex CLI, Gemini CLI, GitHub Copilot and Cursor from the Mac app, so you can check them from your browser. For Claude, the popup shows whichever reading is newer. ChatGPT and Codex CLI appear as separate tabs, since they have separate limits (extension 1.1.2, rolling out now).

Settings that sync

  • Tab order syncs both ways. Rearrange tabs in either one and the other follows; the most recent change wins.
  • Turning a tool on or off syncs both ways: switch it off in the Mac app's settings or the extension's, and it's hidden in both. The most recent change wins. (Coming in the Mac app's next update, 2.10.5. Until then, switch it off in both.)
  • Refresh works across both: refreshing in the Mac app asks the extension to re-read its sites within a minute, and refreshing in the extension makes the Mac app re-check its tools.

What never crosses over

Only usage numbers and these few settings. Your sign-ins, cookies and API keys stay where they are: a key you paste into the extension never reaches the Mac app, and the other way round.

The link is entirely on your computer. When the extension has new numbers, your browser hands them to a small helper inside Tokenomics.app, which saves them to a file the Mac app reads. Nothing goes over the internet. This is the “communicate with cooperating native applications” permission Chrome mentions; see what the extension can access.

Setting up the link

  1. Install the Mac app and the browser extension.
  2. Open the Mac app at least once after installing the extension. That's when it sets up the link, for Chrome (including Beta and Canary), Edge, Brave, Vivaldi, Opera and Arc.
  3. Open the extension's popup. Your web tools appear in the Mac app shortly after.
