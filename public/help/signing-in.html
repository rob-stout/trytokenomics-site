Help / Getting set up

How does signing in work?

There's nothing to sign in to. The Mac app reads the sign-in your coding tools already keep, the extension uses the sites you're signed in to, and Stability AI and Runway take an API key.

Tokenomics has no account of its own, and you never give it a password. It uses the sign-ins you already have:

  • Coding tools (Claude Code, Codex CLI, Gemini CLI, GitHub Copilot, Cursor): the Mac app reads the sign-in those tools already saved on your Mac. There's nothing to paste.
  • Web tools (ChatGPT, Gemini, Midjourney and the rest): the browser extension uses the sites you're signed in to, the same way the site's own pages do.
  • Stability AI and Runway: paste an API key once during setup. The Mac app keeps it in the macOS Keychain.

If a coding tool isn't installed or signed in yet, guided setup does it for you, in Terminal or your browser (what setup installs). For Claude Code, macOS asks once before Tokenomics can read its sign-in; see the Keychain prompt.

Tokenomics never copies your sign-in anywhere else. The specifics are itemized on the Privacy page.
