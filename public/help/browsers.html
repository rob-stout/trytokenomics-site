Help / Getting set up

Which browsers does the extension work in?

Google Chrome, plus Brave, Arc, Vivaldi and Opera from the Chrome Web Store. Versions for Microsoft Edge and Safari are on the way.

Google Chrome. Install it from the Chrome Web Store.

It's a standard Chromium extension, so other Chromium browsers like Brave, Arc, Vivaldi and Opera can install it from the Chrome Web Store too.

Versions for Microsoft Edge (on Edge Add-ons) and Safari (Tokenomics for Safari, a free app on the Mac App Store) are in review. We'll link them here as soon as they're live. Firefox isn't supported.

Use Safari day to day? You can still track your web tools now; see tracking web tools if you use Safari.

If you also run the Mac app, it links up with Chrome (including Beta and Canary), Edge, Brave, Vivaldi, Opera and Arc, so your readings reach the menu bar and widgets from any of them.
