Help / How AI limits work

How do Codex usage limits work?

Codex in a ChatGPT plan has its own allowance: 5-hour and weekly on Plus, weekly only on Pro, monthly on Go. Local tasks, cloud tasks and image generation all draw from it.

Windows by plan

  • Plus and Business (Standard seats): a 5-hour allowance and a weekly allowance. The same usage counts against both, but they can reset at different times, so you can hit the 5-hour limit with plenty of the week left.
  • Pro ($100, $200 or $500): weekly only. Pro has no 5-hour limit.
  • Go: a monthly allowance.
  • Free and Go can use Codex in the desktop app; Codex cloud needs Plus or higher.

What counts

  • Local messages (CLI, editor, desktop app) and cloud tasks share the allowance. Cloud tasks tend to use more.
  • Image generation counts too, at about 3–5× the rate.
  • Code reviews run from GitHub (tagging @Codex) are counted separately.
  • Sessions using an API key are billed at API rates, not from your plan.

OpenAI publishes rough ranges, not fixed limits: on Plus, a 5-hour window ranges from a handful of messages on the largest models to a few thousand on the smallest.

Codex and ChatGPT

Codex already shares its allowance with ChatGPT Work, ChatGPT for Excel and Workspace Agents. From December 2026, Plus, Pro and Business plans share one allowance across ChatGPT chat and Codex too. How ChatGPT limits work.

When you hit a limit

The current turn can usually finish. Then wait for the reset, switch to a smaller model, use a banked reset, buy credits (Plus and Pro), upgrade, or switch to an API key.

Where to check

Type /status in a Codex CLI session, or open chatgpt.com/codex/settings/usage.

In Tokenomics

The Mac app reads the limits Codex CLI writes to your Mac after each run, so the numbers update when you use Codex locally. Cloud tasks show up after your next local run. Why Codex numbers sometimes don't change.

Checked against each provider's own pages in November 2026. Providers change limits often, so their usage page is the final word.
