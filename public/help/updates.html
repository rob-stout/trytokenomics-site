How do updates work?

The Mac app checks for updates automatically and tells you when one is ready; you choose when to install it. The extension updates itself through the Chrome Web Store.

The Mac app checks for new versions automatically. When one is ready you get a “Tokenomics Update Available” notification, and Settings shows a blue dot on Update Available. Click it to install.

To check yourself, open Settings and click Check for Updates. Your current version is shown next to it.

Installed with Homebrew? The app updates itself the same way, so there's no need to run brew upgrade.

The browser extension updates through the Chrome Web Store, usually within a few hours of a release. When an update needs access to a new site, Chrome asks you to approve it first.

What changed in each version is on the changelog.
