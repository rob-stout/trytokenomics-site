Help / How AI limits work

How do GitHub Copilot's usage limits work?

Since June 2026, monthly Copilot plans use AI credits (1 credit = $0.01): Pro gets 1,500 a month, Pro+ 7,000, Max 20,000. Annual Pro and Pro+ plans still use premium requests. Everything resets on the 1st.

AI credits (most plans, since June 2026)

Copilot now charges by tokens at each model's published rate, in AI credits (1 credit = $0.01). Each month includes:

  • Pro ($10): 1,500 credits (1,000 base + 500 flex)
  • Pro+ ($39): 7,000 (3,900 + 3,100)
  • Max ($100): 20,000 (10,000 + 10,000)
  • Business ($19/seat): 1,900 per user, pooled across the organization
  • Enterprise ($39/seat): 3,900 per user, pooled
  • Free: 2,000 code completions a month, plus limited chat and agent use

Base credits are used first, then flex credits (which GitHub may adjust over time). Chat, the CLI, the cloud agent and third-party agents use credits. Code completions don't on paid plans. Using auto model selection is 10% cheaper.

Premium requests (annual Pro and Pro+ only)

If you pay yearly for Pro or Pro+, you keep the older model until your plan ends: 300 premium requests a month on Pro, 1,500 on Pro+. Each model costs a multiple of a request (a small model can be a fraction, a big one many requests).

What shares the allowance

One allowance covers Copilot in your editor, on github.com and in the CLI. On Business and Enterprise, it's pooled across everyone.

Reset

Midnight UTC on the 1st of each month, whatever day you subscribed. Nothing rolls over.

When you run out

Individuals can upgrade or set a budget for extra usage; the old fallback to a cheaper model is gone. On Business and Enterprise, extra usage is on by default unless an admin turns it off.

Where to check

github.com/settings/billing → AI usage, or your Copilot settings → Usage. In VS Code, click the Copilot icon in the status bar. More ways to check.
