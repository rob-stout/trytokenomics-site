Which AI tools does Tokenomics work with?

From Claude Code and Cursor to ChatGPT, Midjourney and Suno. Here's the full list, what each meter tracks, and how each one connects.

Coding tools connect through the Mac app, which reads the sign-in they already keep on your Mac. Web tools connect through the browser extension, which reads the sites you're signed in to. A few take an API key you paste once.

If you have both the Mac app and the extension, the web tools the extension reads also show in your menu bar and widgets (how they work together). Suno and Udio reach the Mac app in its next update; the extension shows them today.
