Help / Getting set up

How do I set up ElevenLabs?

Visit elevenlabs.io with the extension installed, or paste an ElevenLabs API key into the extension. The Mac app shows whatever the extension reads.

ElevenLabs connects through the browser extension, in one of two ways:

  1. Open elevenlabs.io in your browser while signed in. The extension picks up the access your browser already has and reads your usage from then on.
  2. Paste an API key into the extension (open the extension's settings and find ElevenLabs). It then reads your usage directly, without you visiting the site. While a key is set, the extension stops using your site sign-in. Remove the key to go back.

The Mac app shows the extension's reading in your menu bar and widgets. It updates every few minutes while your browser is open; with the browser closed, the Mac app keeps the last reading. If you added an ElevenLabs key in an earlier version of the Mac app, it keeps using that key instead.

Making a key

In ElevenLabs, open API Keys and create a key. Set “User” to “Access” and leave everything else on “No Access”. That's all Tokenomics needs, and a key like that can't generate audio or change your account. If the key is missing that permission, Tokenomics won't save it and tells you why.

Things you might notice

  • Reset dates on Free accounts. ElevenLabs sometimes keeps reporting the first month's reset date long after it passed. Characters still refresh monthly on that day, so Tokenomics counts forward to the next one.
  • The extension saves keys on your device, in your browser's extension storage, unencrypted. Use a key with only the “User” permission so it's harmless if it ever leaked.
