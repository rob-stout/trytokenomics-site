Help / Getting set up

What does guided setup install on my Mac?

Only what each coding tool needs: Homebrew, Node.js, the tool itself, and for Claude Code a line that adds it to your PATH. Terminal opens for installs and sign-ins.

Guided setup installs a coding tool only if you don't already have it. Each step has a way to skip it.

  • Homebrew, the standard Mac package manager, if Copilot, Codex CLI or Gemini CLI needs it. This opens Terminal and asks for your Mac password.
  • Node.js, through Homebrew, for Codex CLI and Gemini CLI.
  • Codex CLI and Gemini CLI, into a folder of their own: ~/.tokenomics-cli.
  • GitHub CLI (gh), through Homebrew, for Copilot.
  • Claude Code, using Anthropic's own installer, into ~/.local/bin. Setup also adds one line to ~/.zprofile (or ~/.bash_profile) so your Terminal can find it.

Signing in to these tools happens in Terminal or your browser, the same as if you set them up yourself. During Claude Code's sign-in, macOS may ask whether it can access folders like Music or Photos. It doesn't need them, so it's safe to say no.

Uninstalling Tokenomics doesn't remove these tools, because you may use them on their own. See how to uninstall if you want them gone too. Step-by-step details for each tool are in the setup guide.
