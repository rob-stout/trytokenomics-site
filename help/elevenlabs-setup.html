Help / Getting set up

How do I set up ElevenLabs?

Sign in at elevenlabs.io with the extension installed, or paste an API key into the extension or the Mac app. Here's how each works and how to make a safe key.

There are three ways, and you can use any of them:

  1. Sign in at elevenlabs.io in your browser, with the extension installed. It reads your usage using that sign-in.
  2. Paste an API key into the extension (open the extension's Settings and find ElevenLabs). It reads your usage directly, without you visiting the site. While a key is set, the extension stops using your site sign-in. Remove the key to go back.
  3. Paste an API key into the Mac app (gear icon → Providers → ElevenLabs). It reads your usage even when your browser is closed.

Which one shows in the Mac app?

If you've pasted a key into the Mac app, it uses that key. If you haven't, it shows the numbers the extension reads, which update every few minutes while your browser is open. It never uses both at once. Your key never moves between the extension and the Mac app; only the usage numbers do.

Making a key

In ElevenLabs, open API Keys and create a key. Set “User” to “Access” and leave everything else on “No Access”. That's all Tokenomics needs, and a key like that can't generate audio or change your account. If the key is missing that permission, Tokenomics won't save it and tells you why.

Things you might notice

  • Reset dates on Free accounts. ElevenLabs sometimes keeps reporting the first month's reset date long after it passed. Characters still refresh monthly on that day, so Tokenomics counts forward to the next one.
  • The extension saves keys on your device, in your browser's extension storage, unencrypted. Use a key with only the “User” permission so it's harmless if it ever leaked. The Mac app keeps its key in your Mac's Keychain.
  • Without a Mac app key, the Mac app only updates while your browser is open. Close the browser and the Mac app keeps showing the last numbers it got.
