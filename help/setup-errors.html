Help / Fixing problems

Guided setup showed an error. What do I do?

What each guided-setup message means and how to get past it: Terminal permission, Homebrew prompts, sign-in not detected, and more.

  • “Tokenomics needs permission to open Terminal.” Setup uses Terminal to install tools and sign you in. Click Open System Settings, go to Privacy & Security → Automation, and allow Tokenomics to control Terminal.
  • “Homebrew install was cancelled. You'll need to approve the admin prompt to continue.” Installing Homebrew needs your Mac password. Run the step again and enter it when Terminal asks.
  • “Homebrew couldn't download.” Check your internet connection and try again.
  • “The install didn't complete.” Something went wrong inside Homebrew. Run brew doctor in Terminal to see what, then try again.
  • “We didn't detect a sign-in. If you finished signing in, tap Check now.” Finish signing in in Terminal or your browser, then click Check now.
  • “Sign-in was cancelled.” Start the step again when you're ready.
  • “We couldn't find … after installing it.” Click to re-run detection. If it still fails, quit and reopen Tokenomics.
  • “Permission denied writing to …” Click Clear cache & retry.
  • “We couldn't securely store your sign-in.” macOS blocked the Keychain. Open Keychain Access and check that your login keychain is unlocked.

Every install step also has a way to skip it if you already have that tool. The setup guide walks through each tool, and what setup installs lists everything it adds.
